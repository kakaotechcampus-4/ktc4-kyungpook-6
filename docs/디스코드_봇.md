# 디스코드 봇

팀 채널에서 쓰는 봇입니다. 예약 메시지와 PR 현황 조회를 합니다.

소스와 배포 방법은 [`bot/README.md`](../bot/README.md) 에 있습니다. 이 문서는 **쓰는 쪽** 설명입니다.

## 명령어

| 명령어 | 하는 일 |
|---|---|
| `/예약 시각 내용` | 지정한 시각에 그 채널로 메시지를 보냅니다 |
| `/예약목록` | 내가 건 예약을 봅니다 |
| `/예약취소 번호` | 내가 건 예약을 취소합니다 |
| `/pr상태` | 열린 PR 을 요약해 봅니다 |

**입력과 응답은 전부 본인에게만 보입니다.** 새벽에 예약을 걸어도 채널에는 아무것도 남지
않고, 지정한 시각이 되면 봇이 대신 보냅니다.

받는 시각 형식 (전부 한국 시간):

```
30분후 · 2시간뒤 · 09:00 · 내일 09:00 · 10-02 09:00 · 2026-10-02 09:00
```

`09:00` 처럼 날짜를 생략했는데 이미 지났으면 **내일** 같은 시각으로 봅니다. 날짜를 적었는데
과거면 오타로 보고 거부합니다.

## 알아 둘 것

- **발송은 1분 단위입니다.** cron 이 1분마다 돌아서 지정 시각보다 최대 1분 늦을 수 있습니다.
- **한 사람당 예약 20건까지.** 실수로 쌓는 것을 막는 선입니다.
- **남의 예약은 보이지도, 취소되지도 않습니다.** 없는 번호와 남의 번호에 같은 문구로 답합니다 —
  번호를 넣어 보며 다른 사람의 예약이 있는지 알아낼 수 없게 하려는 것입니다.
- **예약 메시지는 `@everyone` 을 울리지 않습니다.** 본문에 적혀 있어도 멘션으로 치지 않습니다.

## 권한

봇에 준 권한은 여섯 개입니다. 서버에 추가할 때 운영진이 승인한 범위입니다.

| 권한 | 왜 필요한가 |
|---|---|
| 채널 보기 | 채널에 들어갈 수 있어야 보냅니다 |
| 메시지 보내기 | 예약 발송 |
| 스레드에서 메시지 보내기 | 스레드 안에서 `/예약` 을 걸면 거기로 보냅니다 |
| 링크 임베드 | `/pr상태` 의 PR 링크가 미리보기로 펼쳐집니다 |
| 파일 첨부 | 리포트·로그를 올릴 때 |
| 반응 추가 | 처리 완료를 ✅ 로 표시하는 식 |

**일부러 뺀 것**도 있습니다. `메시지 기록 읽기`·`메시지 관리`·`@everyone 멘션` 은 지금 기능에
필요 없고, 권한을 적게 들고 있을수록 사고가 날 자리가 줄어듭니다.

### 기능을 늘릴 때

**명령어를 추가·수정하거나 코드를 고치는 데는 운영진 승인이 필요 없습니다.** 봇 토큰으로
Discord 에 등록하고 우리 Cloudflare 계정에 배포하면 끝입니다.

```bash
cd bot
npm run setup:token   # 명령어 등록
npm run deploy        # 코드 배포
```

다만 **위 표에 없는 권한이 필요해지면** 초대 링크를 새 권한으로 다시 만들어 운영진에게
재승인을 받아야 합니다. 예: 남의 메시지를 고정하려면 `메시지 관리` 가 필요합니다.

## 문제가 생기면

- 명령어가 안 보입니다 → 전역 등록은 Discord 반영에 최대 1시간 걸립니다
- 예약한 메시지가 안 왔습니다 → 봇이 그 채널을 볼 수 있는지 확인해 주세요
- 그 외 → `bot/README.md` 의 배포·로그 확인 방법을 보세요
